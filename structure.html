📁 폴더 속 파일은 각각 무슨 일을 하나요?

  

    

      
파일쉽게 말하면

      
my_api/main.py주방장의 레시피북. “/health 요청 오면 ok라고 답해”, “/messages 요청 오면 창고에서 꺼내줘” 같은 규칙이 적혀 있어요.

      
my_api/.env비밀 쪽지. 창고 주소와 열쇠가 적혀 있어요. 절대 인터넷(GitHub)에 올리면 안 됩니다. (.gitignore가 막아줘요)

      
my_api/requirements.txt장보기 목록. 서버가 쓰는 도구들(fastapi, supabase …)

      
my_api/schema.sql창고 선반 설계도. Supabase에 messages 표를 만드는 명령

      
my_api/railway.jsonRailway에게 주는 가동 지시서. “uvicorn으로 켜고 /health로 살아있는지 확인해”

      
frontend/index.html손님이 보는 메뉴판과 주문서. 입력창, 저장 버튼

      
frontend/vercel.jsonVercel용 간단 설정

    

  


  
🏠 내 컴퓨터 vs ☁️ 인터넷 (127.0.0.1:8000 의 정체)

  

    

      
지금 하는 것로컬 테스트

      
    
        
  • 127.0.0.1 = “바로 이 컴퓨터”를 가리키는 주소. 나만 접속 가능.
    • 
        
  • 8000 = 건물의 호수. 한 컴퓨터에서 여러 프로그램이 번호로 구분돼요.
    • 
        
  • 여기서는 Railway가 필요 없습니다. 내 컴퓨터에서 uvicorn main:app 명령으로 파이썬이 main.py를 직접 실행해요.
    • 
        
  • Supabase만 진짜 인터넷 서비스를 씁니다.
    • 
      

    

    

      
나중에배포 (인터넷 공개)

      
    
        
  • Railway가 “내 컴퓨터 대신 24시간 켜져 있는 컴퓨터”가 되어 같은 main.py를 실행해요.
    • 
        
  • Vercel이 화면 파일(frontend)을 전 세계에 보여줘요.
    • 
        
  • 그러면 주소가 127.0.0.1:8000 → https://내앱.up.railway.app 으로 바뀝니다.
    • 
        
  • 비밀 쪽지(.env) 대신 Railway의 Variables 메뉴에 같은 값을 입력해요.
    • 
      

    

  

  
그래서 코드 속 load_dotenv()는 “내 컴퓨터면 .env를 읽고, Railway면 Variables를 쓴다”는 뜻이에요. 같은 코드가 어디서든 동작하는 이유입니다.
